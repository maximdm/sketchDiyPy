Page (size · color · grid · rulers)

Set the artboard size in the current units, its background colour, the grid colour/visibility, and whether the measurement rulers show. Changes apply live and are saved with the document.

Image → paths (trace)

Upload a logo or photo and trace it into editable path objects. Works best on dark shapes over a light background; use Edges for line art.

Templates (M4)

Pick a starter layout, set its size, and generate. Built from the console helpers (row/column/grid/ connect); edit the result or open the console to see the code.

Projects (M5)

Your work auto-saves to this browser. Save named copies on the server, or press Ctrl+Z to undo.

Layers (M5)

Group objects into named layers. Click a layer to make it active (new shapes go there) and select its objects. Toggle visibility (👁) to hide a layer in the canvas and every export, or lock (🔒) to keep its objects from being moved.

3D Solid (build123d)

Turn the sketch into a solid. Select shapes first and use Build selection, or Build all for the whole page. Drag to rotate, scroll to zoom. STEP export needs build123d installed. For Revolve, set the spin axis (a vertical line in the sketch): enter its X in mm, or click Pick axis and click the sketch. For Sweep, select a closed profile plus an open path (a line or path shape) — the profile is swept along the path into a solid.

Sweep needs a closed profile plus an open path (a line or path shape). Select both, then build.

Python console (Hybrid mode)

Try: rect(450, 350, 120, 80, fill="#ffe066") or clear() then build a layout. Helpers: rect, circle, line, path, text, dimension, add, clear, doc. Link objects with connect(a, b, "left", "right"); arrange groups with row(parts), column(parts), grid(parts, 3).
