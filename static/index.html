Page (size · color · grid · rulers)

Set the artboard size in the current units, its background colour, the grid colour/visibility, and whether the measurement rulers show. Changes apply live and are saved with the document.

Image → paths (trace)

Upload a logo or photo and trace it into editable path objects. Works best on dark shapes over a light background; use Edges for line art.

Templates (M4)

Pick a starter layout, set its size, and generate. Built from the console helpers (row/column/grid/ connect); edit the result or open the console to see the code.

Projects (M5)

Your work auto-saves to this browser. Save named copies on the server, or press Ctrl+Z to undo.

Layers (M5)

Group objects into named layers. Click a row to make it active (new shapes land there) and select its objects. Drag rows to reorder (stacking) or use ↑/↓. Toggle 👁 (hide in canvas + every export), 🔒 (lock), ○ (solo — show only this layer) and the colour tag. To organise existing art, select it on the canvas, pick a target below, then Move selection ▸.

Python console (Hybrid mode)

Try: rect(450, 350, 120, 80, fill="#ffe066") or clear() then build a layout. Helpers: rect, circle, line, path, text, dimension, add, clear, doc. Link objects with connect(a, b, "left", "right"); arrange groups with row(parts), column(parts), grid(parts, 3). Switch to 3D Model (top) to extrude the result.
